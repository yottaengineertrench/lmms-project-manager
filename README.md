## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Project Library** | Organize LMMS projects by genre, BPM and production status |
| **Plugin Manager** | Track installed LMMS plugins with instrument and effect notes |
| **Soundfont Library** | Organize soundfont files with instrument range and quality notes |
| **Beat Notes** | Document beat and arrangement decisions per production session |
